ANDRADE STORE — PAINEL COMPLETO

Arquivos:
- index.html = site público
- admin.html = painel para adicionar/editar/excluir produtos e categorias
- config.js = configuração do Supabase
- supabase.sql = banco e armazenamento de fotos

CONFIGURAÇÃO ÚNICA:
1. Criar projeto no Supabase.
2. Abrir SQL Editor e executar supabase.sql.
3. Criar um usuário em Authentication > Users para entrar no painel.
4. Copiar Project URL e anon public key para config.js.
5. Publicar os arquivos no GitHub Pages.

Depois disso você não precisa editar código para cadastrar produtos.
No painel você poderá selecionar várias fotos de uma vez; no site elas aparecem como uma galeria que desliza no celular.

NUNCA coloque a chave service_role no site.
